Gaussian Naïve Bayes

$Y \sim \mbox{Bernoulli}(\pi)$ $\prob{P}{X_i = \vec{x}_i|Y = y_k} = \frac{1}{\sigma_{ik}\sqrt{2\pi}} e^{-\frac{(\vec{x}_i - \mu_{ik})^2}{2\sigma_{ik}^2}}$
Different mean and variance for each class $k$ and each pixel $i$.$^*$
Let's assume variance is independent of class: $\sigma_{ik} = \sigma_{i}$

Gaussian NB as a linear classifier

$\prob{P}{X_i = \vec{x}_i|Y = y_k} = \frac{1}{\sigma_{ik}\sqrt{2\pi}} e^{-\frac{(\vec{x}_i - \mu_{ik})^2}{2\sigma_{ik}^2}}$
  • For simplicity consider 2 class problem $\sigma_{i,0} = \sigma_{i, 1}$
  • Decision boundary:
    $\prod_{i=1}^d \prob{P}{x_i|y=0}\prob{P}{y=0} = \prod_{i=1}^d \prob{P}{x_i|y=1}\prob{P}{y=1}$
  • Equivalently:
    $\log\frac{\prod_{i=1}^d \prob{P}{x_i|y=0}\prob{P}{y=0}}{\prod_{i=1}^d \prob{P}{x_i|y=1}\prob{P}{y=1}} = 0$ $\log\frac{\prod_{i=1}^d \prob{P}{x_i|y=0}\prob{P}{y=0}}{\prod_{i=1}^d \prob{P}{x_i|y=1}\prob{P}{y=1}}= \log\frac{1 - \pi}{\pi} +\sum_{i=1}^d \log\frac{\prob{P}{x_i|y=0}}{\prob{P}{x_i|y=1}}$

Gaussian NB as a linear classifier

  • Decision boundary:
    $\log\frac{\prod_{i=1}^d \prob{P}{x_i|y=0}\prob{P}{y=0}}{\prod_{i=1}^d \prob{P}{x_i|y=1}\prob{P}{y=1}} = 0$ $\log\frac{\prod_{i=1}^d \prob{P}{x_i|y=0}\prob{P}{y=0}}{\prod_{i=1}^d \prob{P}{x_i|y=1}\prob{P}{y=1}}= \log\frac{1 - \pi}{\pi} +\sum_{i=1}^d \log\frac{\prob{P}{x_i|y=0}}{\prob{P}{x_i|y=1}}$
  • If you do the algebra:
    $\log\frac{1 - \pi}{\pi} +\sum_{i=1}^d \frac{\mu^2_{i,1} - \mu^2_{i,0}}{2\sigma_i^2} + \sum_{i=1}^d \frac{\mu_{i,1} - \mu_{i,0}}{\sigma_i^2} x_i = w_0 + \sum_{i=1}^d w_i x_i$

Gaussian NB implies Logistic Sigmoid!

  • From previous slide, the log-odds ratio is linear:
    $\log\frac{\prob{P}{Y=1|\vec{x}}}{\prob{P}{Y=0|\vec{x}}} = w_0 + \sum_{i=1}^d w_i x_i = w_0 + \vec{w}^T\vec{x}$
  • Invert to solve for the posterior $\prob{P}{Y=1|\vec{x}}$:
    $\prob{P}{Y=1|\vec{x}} = \frac{1}{1 + \exp(-(w_0 + \vec{w}^T\vec{x}))} = \sigma(w_0 + \vec{w}^T\vec{x})$
  • Same functional form! But GNB assumes conditional independence & normality, whereas Logistic Regression learns $\vec{w}$ directly.
In Lecture 10, we saw that Gaussian Naive Bayes models class-conditional distributions as Gaussians with diagonal covariance. When variances are shared between classes, the quadratic terms cancel completely! The log-posterior odds ratio is strictly linear: w0 + w^T x. When you invert this log-odds equation to solve for P(Y=1|x), you get the logistic sigmoid! This reveals a profound truth: Gaussian Naive Bayes and Logistic Regression share the EXACT same posterior form. So what is the difference? GNB is generative: it fits means and variances by joint MLE, assuming independence. Logistic Regression is discriminative: it learns w directly by conditional MLE without assuming Gaussianity or independence!

Notice the difference between the two models. When features are uncorrelated (rho = 0), GNB's conditional independence assumption holds, and its boundary is identical to Logistic Regression. But when features are correlated (rho = 0.8), the true clusters tilt diagonally. Because GNB assumes independence, it is forced to fit axis-aligned ellipses! Its boundary cuts sub-optimally across the data, dropping accuracy. Logistic regression, on the other hand, makes NO independence assumption: it learns the boundary directly, automatically rotating with the correlation!

Generative vs. Discriminative

  • Generative classifiers (such as Naïve Bayes)
    • Assume a functional form for $\prob{P}{x,y}$ (or $\prob{P}{x|y}$ and $\prob{P}{y}$)
    • Estimate parameters of $\prob{P}{x|y}$ and $\prob{P}{y}$ from training data
    • Able to generate samples from a trained model
  • Note:
    $\underset{y}{\argmax} \prob{P}{x|y}\prob{P}{y} = \underset{y}{\argmax} \prob{P}{y|x}$
  • Let's learn $\prob{P}{y|x}$ directly!
  • Or learn the decision boundary directly

Problem definition

Logistic regression seeks to
  • Model the probability of an event occuring depending on the values of the independent variables, which can be categorical or numerical
  • Estimate the probability that an event occurs for a randomly selected observation versus the probability that the event does not occur
  • Predict the effect of a series of variables on a binary response variable
  • Classify observations by estimating the probability that an observation is in a particular category (e.g. approved or not approved for a loan)

Our data in 1D: Why Not Linear Regression?

Bounding Probabilities & Robustness to Outliers

Scenarios:
7.5
Why not just fit a straight line with Ordinary Least Squares? First, linear regression predicts values below 0 and above 1, which violate probability axioms. Second, squared error penalizes points that are "too correct": if a patient has an extreme symptom (x = 8) with label y = 1, the squared error (w*x + b - 1)^2 severely penalizes the line! It forces the line to rotate, shifting the 0.5 decision threshold to the right and misclassifying true positives. Logistic regression fixes both: its sigmoid squashes outputs to (0, 1), and because the sigmoid saturates, distant points produce near-zero gradient and never corrupt the threshold!

What's the probability?

  • $\log\left(\frac{p_+}{1-p_+}\right) = \vec{w}^T\vec{x}$
  • $\frac{p_+}{1-p_+} = e^{\vec{w}^T\vec{x}}$
  • $p_+ = e^{\vec{w}^T\vec{x}}(1-p_+)$
  • $p_+ = e^{\vec{w}^T\vec{x}}-p_+e^{\vec{w}^T\vec{x}}$
  • $p_++p_+e^{\vec{w}^T\vec{x}} = e^{\vec{w}^T\vec{x}}$
  • $p_+(1+e^{\vec{w}^T\vec{x}}) = e^{\vec{w}^T\vec{x}}$
  • $p_+ = \frac{e^{\vec{w}^T\vec{x}}}{1+e^{\vec{w}^T\vec{x}}}$
  • $p_+ = \frac{1}{1+e^{-\vec{w}^T\vec{x}}}$

Level Set P=0.5: Hyperplane  |  Surface: Sigmoid Ramp
Presets:
Let's address the fundamental geometric nature of Logistic Regression: 1. Is Logistic Regression a linear or nonlinear classifier? It is STRICTLY a linear classifier! The decision boundary where P(Y=1|x) = 0.5 is defined by w^T x + w0 = 0. In 2D, this is a straight line; in d dimensions, it is a flat linear hyperplane. 2. However, the probability output P(Y=1|x) = sigma(w^T x + w0) is a nonlinear sigmoidal surface (shown in 3D on the right). It squashes the real line to (0, 1), producing an S-shaped ramp perpendicular to the hyperplane boundary. 3. Notice that all parallel contour lines in feature space are linear hyperplanes. The normal vector w determines the orientation and steepness of the ramp, while w0 shifts the hyperplane across feature space without rotating it. Drag the 3D perspective to see how the flat hyperplane level set cuts through the middle (p=0.5) of the sigmoidal ramp.

What's the probability when it is interesting?

  • $\prob{P}{G=k|X=x} = \frac{e^{\vec{w}_k^T\vec{x}}}{1+\sum_i^{K-1}e^{\vec{w}_i^T\vec{x}}}, k = 1, \dots, K-1$
  • $\prob{P}{G=K|X=x} = \frac{1}{1+\sum_i^{K-1}e^{\vec{w}_i^T\vec{x}}}$

Solving Logistic regression

An alternative perspective on log odds

What's posterior probability of class $c_1$ given a sample $\vec{x}$?
\[ \prob{p}{c_1|\vec{x}} = \frac{\prob{p}{\vec{x}|c_1}\prob{p}{c_1}}{\prob{p}{\vec{x}|c_1}\prob{p}{c_1} + \prob{p}{\vec{x}|c_2}\prob{p}{c_2}} \]
Let's introduce $a = \ln\frac{\prob{p}{\vec{x}|c_1}\prob{p}{c_1}}{\prob{p}{\vec{x}|c_2}\prob{p}{c_2}}$
\[ \prob{p}{c_1|\vec{x}} = \frac{1}{1+\exp{(-a)}} = \sigma(a) \]

Logistic Sigmoid

Nice properties of logistic sigmoid \begin{align} \sigma{(-a)} &= 1 - \sigma{(a)}\\ \end{align} $a = \ln{(\frac{\sigma}{1 - \sigma})} \color{#dc322f}{\text{ log odds???}}$
$\frac{d\sigma}{d a} =\sigma(1-\sigma)$

Maximum likelihood estimate

\begin{align} {\cal l}(\vec{w}) &= \underset{\vec{w}}{\argmax} \prod_i^N P_{\vec{w}}(c_k | x_i)\\ {\cal l}(\vec{w}) &= \underset{\vec{w}}{\argmax} \prod_{i:\vec{x}_i \in c_1}^N P_{\vec{w}}(c_1 | x_i)\prod_{i:\vec{x}_i \in c_2}^N P_{\vec{w}}(c_2 | x_i)\\ {\cal l}(\vec{w}) &= \underset{\vec{w}}{\argmax} \prod_{i:\vec{x}_i \in c_1}^N \sigma \prod_{i:\vec{x}_i \in c_2}^N (1 - \sigma)\\ {\cal l}(\vec{w}) &= \underset{\vec{w}}{\argmax} \prod_i^N \sigma_i^{l_1}(1 - \sigma_i)^{1-l_1}\\ \end{align}

Negative Log likelihood

\begin{align} {\cal l}(\vec{w}) &= \underset{\vec{w}}{\argmax} \prod_i^N \sigma_i^{l_1}(1 - \sigma_i)^{1-l_1}\\ \ell(\vec{w}) &= - \sum_i^N ({l_i}\ln(\sigma_i) + (1-l_i)\ln(1 - \sigma_i))\\ \end{align}

Cross Entropy (recap)

\[ H_{p,q} = -\sum_{i=1}^n p_X(x_i) \log q_X(x_i) \]

Negative Log likelihood: How to solve for $\vec{w}$?

\begin{align} \ell(\vec{w}) &= - \sum_i^N ({l_i}\ln(\sigma_i) + (1-l_i)\ln(1 - \sigma_i))\\ \nabla_{\vec{w}} \ell &= \sum_i^N (\sigma_i - l_i)\vec{x}_i\\ \nabla_{\vec{w}} \ell &= {\bf X}^T (\vec{\sigma} - \vec{l}) \stackrel{\text{set}}{=} 0\\ \end{align}

Taylor expansion

\[ f(x) = f(a)+\frac {f^\prime(a)}{1!} (x-a)+ \frac{f''(a)}{2!} (x-a)^2+ \cdots \] \[ f(x) = \sum_{n=0} ^ {\infty} \frac {f^{(n)}(a)}{n!} (x-a)^{n} \]

Taylor series allows us to locally approximate any smooth function with polynomials: • Order 1 (Linear): f(x) ≈ f(a) + f'(a)(x-a). This is a flat tangent line. Gradient Descent moves along the negative slope -f'(a). • Order 2 (Quadratic): f(x) ≈ f(a) + f'(a)(x-a) + 0.5 f''(a)(x-a)^2. This is an osculating parabola! Notice the purple diamond marker: setting the derivative of this parabola to zero gives the vertex at delta = -f'(a)/f''(a). That vertex IS the exact Newton-Raphson step! On the very next slide, we will apply this exact 2nd-order Taylor expansion to the negative log-likelihood of logistic regression to derive IRLS.

Newton-Raphson method

\begin{align} \ell(\vec{w} + \Delta) & = \ell(\vec{w}) + \ell^{\prime}(\vec{w})\Delta + \frac{1}{2}\ell^{\prime\prime}(\vec{w})\Delta^2\\ \frac{\partial \ell(\vec{w} + \Delta)}{\partial \Delta} & \stackrel{set}{=} 0 \\ \ell^{\prime}(\vec{w}) + \ell^{\prime\prime}(\vec{w})\Delta &= 0\\ \Delta &= - \frac{\ell^{\prime}(\vec{w})}{\ell^{\prime\prime}(\vec{w})}\\ \vec{w}_{new} & = \vec{w}_{old} + \Delta = \vec{w}_{old}- \frac{\ell^{\prime}(\vec{w})}{\ell^{\prime\prime}(\vec{w})}\\ \vec{w}_{new} & = \vec{w}_{old} - {\bf H}^{-1}\nabla_\vec{w}\ell \end{align}

Hessian

\[ \mathbf H = \begin{bmatrix} \dfrac{\partial^2 f}{\partial w_1^2} & \dfrac{\partial^2 f}{\partial w_1\,\partial w_2} & \cdots & \dfrac{\partial^2 f}{\partial w_1\,\partial w_n} \\[2.2ex] \dfrac{\partial^2 f}{\partial w_2\,\partial w_1} & \dfrac{\partial^2 f}{\partial w_2^2} & \cdots & \dfrac{\partial^2 f}{\partial w_2\,\partial w_n} \\[2.2ex] \vdots & \vdots & \ddots & \vdots \\[2.2ex] \dfrac{\partial^2 f}{\partial w_n\,\partial w_1} & \dfrac{\partial^2 f}{\partial w_n\,\partial w_2} & \cdots & \dfrac{\partial^2 f}{\partial w_n^2} \end{bmatrix} \]

Newton-Raphson update for linear regression

$f(\vec{w}) = \sum_{i}^{n} (\vec{w}^T\vec{x}_i - y_i)^2$
Let us write in matrix form:
$f(\vec{w}) = (\bf{X}\vec{w} - \vec{y})^T(\bf{X}\vec{w} - \vec{y})$
The gradient:
$\nabla_\vec{w}f = \bf{X}^T\bf{X}\vec{w} - \bf{X}^T\vec{y}$
The Hessian:
$\nabla^2_\vec{w}f = \bf{X}^T\bf{X}$
$\vec{w}_{new} = \vec{w}_{old} - (\bf{X}^T\bf{X})^{-1}(\bf{X}^T\bf{X}\vec{w}_{old} - \bf{X}^T\vec{y})$
$\vec{w}_{new} = \vec{w}_{old} - \vec{w}_{old} + (\bf{X}^T\bf{X})^{-1}\bf{X}^T\vec{y}$
$\vec{w}_{new} = (\bf{X}^T\bf{X})^{-1}\bf{X}^T\vec{y}$

Newton-Raphson update for logistic regression

  • $\nabla_{\vec{w}} \ell = {\bf X}^T (\vec{\sigma} - \vec{l})$
  • ${\bf H} = \nabla\nabla_{\vec{w}} \ell = {\bf X}^T{\bf W}{\bf X}$
  • ${\bf W}_{i,i} = \sigma_i(1-\sigma_i)$
  • $\vec{w}_{new} = \vec{w}_{old} - (\bf{X}^T\bf{W}\bf{X})^{-1}\bf{X}^T(\vec{\sigma} - \vec{l})$
  • bring $(\bf{X}^T\bf{W}\bf{X})^{-1}$ out
  • $\vec{w}_{new} = (\bf{X}^T\bf{W}\bf{X})^{-1}(\bf{X}^T\bf{W}\bf{X}\vec{w}_{old} - \bf{X}^T(\vec{\sigma} - \vec{l}))$
  • $\vec{z} = \bf{X}\vec{w}_{old} - \bf{W}^{-1}(\vec{\sigma} - \vec{l})$
  • $\vec{w}_{new} = (\bf{X}^T\bf{W}\bf{X})^{-1}\bf{X}^T\bf{W}\vec{z}$

Take Home Points

  • Generative vs. Discriminative Bridge: Gaussian NB with equal class variance implies the logistic sigmoid $P(Y=1|X) = \sigma(\vec{w}^T\vec{x})$; Logistic Regression retains this form while dropping normality and feature independence assumptions.
  • Linear Classifier, Nonlinear Probability Surface: The decision boundary $\vec{w}^T\vec{x} + w_0 = 0$ is strictly a flat linear hyperplane in feature space $\mathbb{R}^d$, while the predicted posterior $P(Y=1|\vec{x}) = \sigma(\vec{w}^T\vec{x} + w_0)$ is a bounded nonlinear sigmoidal surface.
  • Convexity & Cross-Entropy: Logistic negative log-likelihood is strictly convex with no local minima; its gradient $\mathbf{X}^T(\vec{\sigma} - \vec{y})$ reflects prediction errors weighted by inputs.
  • Second-Order Optimization (IRLS): Newton-Raphson approximates the loss via its 2nd-order Taylor expansion; the update $\vec{w}_{\text{new}} = (\mathbf{X}^T\mathbf{W}\mathbf{X})^{-1}\mathbf{X}^T\mathbf{W}\vec{z}$ solves iteratively reweighted least squares with Hessian curvature $\mathbf{X}^T\mathbf{W}\mathbf{X}$.
  • Multiclass Softmax & Temperature: Softmax generalizes logistic regression to $K$ classes; temperature scaling smoothly interpolates between uniform distribution ($T \to \infty$) and hard argmax ($T \to 0$).
Review: Gaussian NB equal-variance derivation leading directly to the logistic sigmoid, generative versus discriminative trade-offs, why the decision boundary is strictly a linear hyperplane while the probability surface is nonlinear, strict convexity of cross-entropy, Newton-Raphson as a 2nd-order Taylor expansion yielding IRLS with Hessian X^T W X, and temperature-controlled softmax generalization.
