Bias-variance trade off revisited

Bias-Variance Decomposition for MSE

  • MSE as an error measure
  • $E\left[ (\hat{\theta} - \theta)^2 \right]$
  • $= E\left[ \hat{\theta}^2 - 2 \hat{\theta}\theta + \theta^2\right]$
  • $= E\left[ \hat{\theta}^2\right] - 2 E\left[\hat{\theta}\right] \theta + \theta^2$
  • Add and subtract $E\left[ \hat{\theta} \right]^2$
  • \begin{align} = & E\left[ \hat{\theta} \right]^2 - 2 E\left[\hat{\theta}\right] \theta + \theta^2 \\ & + E\left[ \hat{\theta}^2\right] - E\left[ \hat{\theta} \right]^2 \end{align}
  • \begin{align} = & \underbrace{(E\left[ \hat{\theta} \right] - \theta)^2}_{\text{Bias}^2} + \underbrace{E\left[ \hat{\theta}^2\right] - E\left[ \hat{\theta} \right]^2}_{\text{Variance}} \end{align}
  • Is not variance $E\left[ (\hat{\theta} - E\left[\hat{\theta}\right])^2\right]$?
  • $E\left[ (\hat{\theta} - E\left[\hat{\theta}\right])^2\right]$
  • $= E\left[ \hat{\theta}^2 - 2\hat{\theta}E\left[\hat{\theta}\right] + E\left[\hat{\theta}\right]^2 \right]$
  • $= E\left[ \hat{\theta}^2 \right] - 2 E\left[ \hat{\theta}\right]E\left[\hat{\theta}\right] + E\left[\hat{\theta}\right]^2$
  • $= E\left[ \hat{\theta}^2 \right] - 2 E\left[\hat{\theta}\right]^2 + E\left[\hat{\theta}\right]^2$
  • $= E\left[ \hat{\theta}^2 \right] - E\left[\hat{\theta}\right]^2$

Bias-variance tradeoff

If data is all we have, how do we know which model is better?

Training Error Lies: 100 Random Dataset Splits

Each thin hairline is one random dataset draw $\CD_i$ (vertical spread = Variance). As complexity grows, training error $\downarrow$ monotonically while test error $\uparrow$ and fans out — never select model complexity on training error!
Hastie, Tibshirani & Friedman (2009), The Elements of Statistical Learning, Figure 2.11
- What are the ~100 faint light-blue and light-red hairlines? Each hairline is a different random training/test dataset draw D_i! - The vertical spread of those thin hairlines is literally the VARIANCE of the model across datasets, while the thick blue and red curves are the expected training and test error. - Notice the trap: as model complexity (number of parameters p or polynomial degree k) increases, the blue training error goes monotonically down, while the red test error turns up and its variance explodes. Thus we need a separate validation estimator to pick hyperparameters!

Select a Model That Generalizes Best

We pick hyperparameter $\hat{\theta}_i = \argmin_{\theta} g(\theta; \CD_i)$ by minimizing validation error $g(\theta; \CD_i)$ to approximate true test error $G(\theta)$:
$\EE_{\CD}\!\left[(g(\theta; \CD) - G(\theta))^2\right] = \text{Bias}(g)^2 + \text{Variance}(g)$
Takeaway: A small bias ($\EE[\hat{\theta}] \neq \theta^*$) with low variance stays consistently near $\theta^*$, whereas an unbiased estimator with high variance can pick disastrous $\hat{\theta}_i$ far from $\theta^*$!
Cawley & Talbot (2010): On Over-fitting in Model Selection and Subsequent Selection Bias in Performance Evaluation
- What is this slide saying? Suppose we already trained our models and now want to pick a hyperparameter theta (e.g., kernel bandwidth or regularization strength) that minimizes true test error G(theta) (the green curve, whose true minimum is at theta*). - Since we only have finite data D_i, we use a validation estimator g(theta; D_i) (the blue curves) and pick its minimum theta_hat_i. - Left panel (Unbiased, High Variance — e.g., a single tiny validation split or leave-one-out): On average across datasets (red dashed line), g is unbiased. But on any SINGLE dataset split D_i (thin blue curves), random wiggles cause the minimum theta_hat_i to land anywhere from left to right! You overfit the validation set. - Right panel (Biased, Low Variance — e.g., K-fold cross-validation): Even though g' has non-zero bias (shifted vertically from G(theta)), its variance across splits is tiny, so every blue curve reaches its minimum right around the true optimum theta*! - Bottom takeaway: Adding a bias shift doesn't move the argmin, whereas variance moves the argmin everywhere!

From Classical Bias-Variance to Double Descent

Why the Second Descent? At $p = n$, the unique interpolant has exploding norm $\|\hat{\vth}\|_2 \sim \sigma_{\min}(\vec{X})^{-1} \to \infty$. For $p \gg n$, SGD finds the minimum-norm interpolant $\hat{\vth}_{\text{min}} = \argmin_{\vec{X}\vth = \vec{y}} \|\vth\|_2^2 = \vec{X}^{\top}(\vec{X}\vec{X}^{\top})^{-1}\vec{y}$, whose norm and variance shrink as $p$ grows!
Belkin et al. (2019): Reconciling modern machine learning practice and the bias-variance trade-off
- Step 1 (Initial view): The classical Bias-Variance trade-off (p < n). As capacity grows, Bias^2 drops and Variance rises, creating the U-shaped Test Risk with an optimal "Sweet Spot". - Step 2 (Fragment 1): Extend the capacity axis past the Interpolation Threshold (p = n), where the model first achieves zero training error. Right at p = n, there is only ONE function in H that interpolates the noisy data — it must wiggle violently, causing a sharp variance spike. Beyond p >> n, Test Risk descends a SECOND time! - Step 3 (Fragment 2): Modern explanation — when p >> n, the system X*theta = y is underdetermined with infinitely many zero-error solutions. Gradient descent from zero initialization implicitly converges to the minimum-L2-norm solution. Adding more features/parameters (p >> n) increases the smallest singular value of X*X^T, shrinking ||theta_hat||_2 and reducing variance!

The Rebalancing Paradox: What Happens in the Wild?

Now deploy both classifiers on the true population ($5\%$ Class $0$, $95\%$ Class $1$):
"Winner" Classifier A ($92\%$ on balanced):
• Class $0$ ($5\%$): $100\%$ correct
• Class $1$ ($95\%$): $83\%$ correct
$$\text{ACC}_{\text{wild}}(A) = 0.05(1) + 0.95(0.83) \approx \color{#dc322f}{\mathbf{84\%}}$$
"Loser" Classifier B ($90\%$ on balanced):
• Class $0$ ($5\%$): $80\%$ correct
• Class $1$ ($95\%$): $100\%$ correct
$$\text{ACC}_{\text{wild}}(B) = 0.05(0.80) + 0.95(1) = \mathbf{99\%}$$

Neither $84\%$ nor $99\%$ makes sense without knowing the cost of mistaking $0 \to 1$ vs. $1 \to 0$!

- Initial view: Ask the class: "We picked Classifier A because it got 92% on our 50/50 split. What accuracy does A get when we deploy it in the wild (5% Class 0, 95% Class 1)?" - Fragment 1: A drops from 92% to 84% in the wild! - Fragment 2: Ask: "What about Classifier B, which we rejected?" B gets 99% accuracy in the wild! - Fragment 3: Punchline: raw accuracy (whether unbalanced or rebalanced) cannot tell us which model is better without breaking out the two types of errors!

Confusion Matrix

Two-Class Confusion Matrix

  • Columns ($\mathbf{p}, \mathbf{n}$): True ground-truth class.
  • Rows ($\mathbf{P}, \mathbf{N}$): Classifier predicted class.
  • Main diagonal ($\text{TP}, \text{TN}$): Correct decisions.
  • Off-diagonal ($\text{FP}, \text{FN}$): Two distinct types of mistakes (ideally $0$, but in practice a trade-off!).

Statistician view of the world

Visual Quotient Mnemonic: Accuracy

$$\text{ACC} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}}$$ When $\text{TN}$ is huge, it dominates both the numerator and denominator!

Family 1: Sensitivity & Specificity (Column Quotients)

From video 61 (5qmz7EpvC9U at 05:30): Sensitivity (True Positive Rate) divides TP by the entire True Positive column (P). Specificity (True Negative Rate) divides TN by the entire True Negative column (N).

Family 2: Precision & Recall (Information Retrieval)

From video 61 (5qmz7EpvC9U at 08:30): Precision divides TP by the TOP ROW (everything predicted as positive, e.g., web search results shown to user). Recall divides TP by the LEFT COLUMN (identical to Sensitivity!).

Why One Metric Is Not Enough: How Models Cheat

  • Maximize Recall (Sensitivity) alone?
    Predict Positive ($\mathbf{P}$) for everything $\implies \text{FN} = 0 \implies \mathbf{100\%\text{ Recall}}$ (with massive $\text{FP}$!).
  • Maximize Specificity alone?
    Predict Negative ($\mathbf{N}$) for everything $\implies \text{FP} = 0 \implies \mathbf{100\%\text{ Specificity}}$ (catches $0$ positives!).
  • Maximize Precision alone?
    Set threshold ultra-high and predict $\mathbf{P}$ on only $1$ certain sample $\implies \mathbf{100\%\text{ Precision}}$!

We must combine complementary quotients so the classifier cannot cheat!

Imbalanced Example: Raw Accuracy Rewards Ignoring P

Pred \ True $\mathbf{p}$ $\mathbf{n}$
$\mathbf{P}$ $5$ $50$
$\mathbf{N}$ $10$ $10{,}000$
1. Our Classifier's Accuracy: $$\text{acc} = \frac{5 + 10{,}000}{10 + 5 + 50 + 10{,}000} = \mathbf{99.4\%}$$
2. Dummy "Predict All $\mathbf{N}$" ($\text{TP}=0, \text{FP}=0$): $$\text{acc}_{\text{all-}N} = \frac{0 + 10{,}050}{15 + 10{,}050} \approx \color{#dc322f}{\mathbf{99.9\% > 99.4\%!}}$$

Balanced Accuracy & F1 Score Catch the Cheater

Balanced Accuracy ($\text{BA}$): $$\text{BA} = \frac{\text{Sensitivity} + \text{Specificity}}{2}$$
• Our model ($\begin{smallmatrix}5 & 50\\ 10 & 10000\end{smallmatrix}$):
$\text{Sens} = \frac{5}{15} = 33.3\%$, $\text{Spec} = \frac{10000}{10050} = 99.5\%$ $$\text{BA} = \frac{33.3\% + 99.5\%}{2} = \mathbf{66.4\%}$$ • Predict All $\mathbf{N}$: $\frac{0\% + 100\%}{2} = \color{#dc322f}{\mathbf{50\%}}$ (chance!)
$F_1$ Score (Harmonic Mean of $P, R$): $$F_1 = 2\,\frac{P \cdot R}{P + R}$$
• Our model ($\begin{smallmatrix}5 & 50\\ 10 & 10000\end{smallmatrix}$):
$P = \frac{5}{55} = 9.1\%$, $R = \frac{5}{15} = 33.3\%$ $$F_1 = \frac{2(0.091)(0.333)}{0.091 + 0.333} = \mathbf{14.3\%}$$ • Predict All $\mathbf{N}$: $R = 0 \implies \color{#dc322f}{\mathbf{F_1 = 0\%!}}$
Complete board derivation from frame_cm_2030.png in video 61! Balanced Accuracy drops the all-N cheater to 50% (chance), and F1 drops it to 0%.

Expected Value (profit)

based on: Data Science for Business (chapter 7)

Expected value

  • Let's denote an outcome $i$ as $o_i$
  • The probability of that outcome as $\prob{p}{o_i}$
  • And its value as $\prob{v}{o_i}$
  • The expected value is nothing but $$ EV = \sum_i^K \prob{p}{o_i}\cdot\prob{v}{o_i} $$

Example: targeted marketing

  • A consumer buys the product for $\$200$ and our product-related costs are $\$100$.
  • To target the consumer with the offer, we also incur a cost. Let’s say that we mail some flashy marketing materials, and the overall cost including postage is $\$1$, yielding a value (profit) of $\prob{v}{o_R} = \$99$ if the consumer responds (buys the product).
  • Now, what about $v_{NR}$, the value to us if the consumer does not respond? We still mailed the marketing materials, incurring a cost of $\$1$ or equivalently a benefit of $-\$1$.

Example: shall we target this specific consumer?

  • $\prob{p}{o_R} \cdot \$99 - [1 - \prob{p}{o_{R}}]\cdot \$1 \gt 0$
  • $\prob{p}{o_R} \cdot \$99 \gt [1 - \prob{p}{o_{R}}]\cdot \$1$
  • $\prob{p}{o_R} \gt 0.01$
  • Send marketing materials if probability of responding is $\gt 1\%$

Expected Value Calculation

Example: targeted marketing — What's the profit?

\begin{align} EV = &\, \prob{p}{Y, p} \prob{b}{Y, p} + \prob{p}{N, p} \prob{b}{N, p} + \prob{p}{N, n} \prob{b}{N, n} + \prob{p}{Y, n} \prob{b}{Y, n} \\ = & \fragment{0}{\, \prob{p}{Y| p}\prob{p}{p} \prob{b}{Y, p} + \prob{p}{N|p} \prob{p}{p} \prob{b}{N, p}} \\ & \fragment{0}{+ \prob{p}{N|n} \prob{p}{n} \prob{b}{N, n} + \prob{p}{Y|n} \prob{p}{n} \prob{b}{Y, n}}\\ = &\, \fragment{1}{\prob{p}{p} \left[ \prob{p}{Y| p} \prob{b}{Y, p} + \prob{p}{N|p} \prob{b}{N, p} \right]} \\ & \fragment{1}{+ \prob{p}{n} \left[ \prob{p}{N|n} \prob{b}{N, n} + \prob{p}{Y|n} \prob{b}{Y, n} \right]}\\ =&\, \fragment{2}{0.55 \left[ 0.92\cdot \prob{b}{Y, p} + 0.08\cdot \prob{b}{N, p} \right]} \\ & \fragment{2}{+ 0.45 \left[ 0.86\cdot \prob{b}{N, n} + 0.14\cdot \prob{b}{Y, n} \right]}\\ =&\, \fragment{3}{0.55 \left[ 0.92\cdot99 + 0.08\cdot 0 \right] + 0.45 \left[ 0.86\cdot 0 + 0.14\cdot (-1) \right]}\\ =&\, \fragment{4}{\$50.04} \end{align}

Area Under the ROC Curve (AUC)

What Does AUC Mean Probabilistically?

Equivalent to the Mann-Whitney-Wilcoxon ranking statistic (and Gini coefficient):
$$\text{AUC} = \PP\Big( s(\vec{x}_{+}) > s(\vec{x}_{-}) \Big)$$ The probability that a randomly chosen positive sample $\vec{x}_{+}$ is ranked (scored) higher than a randomly chosen negative sample $\vec{x}_{-}$!
From video 65 (8xe9wzWBdyM at 18:30): AUC integrates the ROC curve inside the unit square (0.5 for random guessing, 1.0 for perfect separation) and equals the probability that a randomly drawn positive instance is scored higher than a randomly drawn negative instance.

On Model Calibration

*based on Guo et al. (2017): On Calibration of Modern Neural Networks

What is Model Calibration?

Model calibration is the problem of predicting probability estimates representative of the true correctness likelihood

Why do we need it?

We want the probability associated with the predicted class label to reflect its ground truth correctness likelihood.
If that is the case, we know when we can trust the model, and when to route the decision to a human!

Modern Best-Performing Models Are Lying

  • 5-layer LeNet (1998) is well-calibrated
  • 110-layer ResNet (2016) achieves much higher accuracy, yet is poorly calibrated (overconfident)
  • Why does this happen, and how do we fix it?

Formal definitions

  • Inputs $X \in {\cal X}$ and labels $Y \in {\cal Y} = \{1, \dots, K\}$ follow ground truth joint distribution $\pi(X,Y) = \pi(Y|X)\pi(X)$.
  • A neural network $h(X) = (\hat{Y}, \hat{P})$ outputs a class prediction $\hat{Y}$ and a confidence score $\hat{P}$.
  • We want the confidence estimate $\hat{P}$ to be calibrated, which intuitively means that $\hat{P}$ represents a true probability.
  • Perfect calibration:
$$ \PP(\hat{Y} = Y \mid \hat{P} = p) = p, \quad \forall p \in [0, 1] $$

Reliability Diagrams

  • Reliability Diagrams visualize model calibration (DeGroot & Fienberg, 1983)
  • Plot expected sample accuracy as a function of confidence
  • Perfect calibration ($\PP(\hat{Y} = Y | \hat{P} = p) = p$) lies on the identity diagonal
  • Any deviation from the diagonal is miscalibration

Calibration Across Classical Classifiers

sklearn: Probability calibration
From video 66 (rRhKGNFyPhg at 06:30): - Logistic Regression directly optimizes log-loss, so it is well-calibrated out of the box. - Support Vector Machines concentrate near 0.5 (sigmoid / Platt scaling needed). - Naive Bayes pushes probabilities toward 0 and 1 because of the conditional independence assumption.

Reliability Diagrams: Binning

  • Group predictions into $M$ interval bins (each of size $1/M$) and calculate the accuracy of each bin.
  • Let $B_m$ be the set of indices of samples whose prediction confidence falls into the interval $I_m = (\frac{m-1}{M}, \frac{m}{M}]$.
  • The accuracy of $B_m$ is: $$ \mbox{acc}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \mathbf{1}(\hat{y}_i = y_i) $$
  • The average confidence within bin $B_m$ is: $$ \mbox{conf}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \hat{p}_i $$

Expected Calibration Error (ECE)

  • We use empirical approximations directly: $$ \EE_{\hat{P}}\left[ \left| \PP(\hat{Y} = Y | \hat{P} = p) - p \right| \right] $$
  • Expected Calibration Error (ECE) — weighted average of the red gap bars across all $M$ bins: $$ \mbox{ECE} = \sum_{m=1}^M \frac{|B_m|}{n} \left| \mbox{acc}(B_m) - \mbox{conf}(B_m) \right| $$
  • Maximum Calibration Error (MCE) — worst-case bin gap for high-risk applications: $$ \mbox{MCE} = \max_{m \in \{1,\dots, M\}} \left| \mbox{acc}(B_m) - \mbox{conf}(B_m) \right| $$

Negative Log-Likelihood (NLL)

  • A standard measure of a probabilistic model's quality (also known as cross-entropy loss in deep learning).
  • Given a probabilistic model $\hat{\pi}(Y|X)$ and $n$ samples: $$ {\cal L} = - \sum_{i=1}^n \log\left(\hat{\pi}(y_i|x_i)\right) $$
  • NLL is a proper scoring rule: in expectation, it is minimized if and only if $\hat{\pi}(Y|X)$ recovers the ground truth conditional distribution $\pi(Y|X)$.

What Affects Calibration?

  • Increasing depth and width reduces classification error, but hurts calibration.
  • Models trained with Batch Normalization or less weight decay are more miscalibrated.

Accuracy vs. NLL During Training

The network overfits NLL (becoming overconfident) long after 0/1 classification error plateaus!

Temperature Scaling

  • The neural network computes a vector of non-probabilistic logits $\vec{z}_i$ for each input $\vec{x}_i$, before the softmax layer $\sigma_{\text{SM}}$: $$ \hat{p}_i = \max_k \sigma_{\text{SM}}(\vec{z}_i)^{(k)} = \max_k \frac{\exp(z_i^{(k)})}{\sum_{j=1}^K \exp(z_i^{(j)})} $$
  • Temperature Scaling divides the logits by a single scalar parameter $T > 0$ before the softmax: $$ \hat{q}_i = \max_k \sigma_{\text{SM}}\left(\frac{\vec{z}_i}{T}\right)^{(k)} $$

Properties of Temperature Scaling

  • $T = 1$: recovers the original uncalibrated probabilities $\hat{p}_i$.
  • As $T > 1$ increases: softens the softmax distribution (raises output entropy) and cures overconfidence.
  • As $T \to \infty$: $\hat{q}_i \to 1/K$ (uniform maximum uncertainty).
  • As $T \to 0$: collapses to a point mass ($\hat{q}_i \to 1$).
  • $T$ is optimized with respect to NLL on the validation set (with network weights frozen).
  • Because $z_i^{(k)} / T$ is strictly monotonic for $T > 0$, $\argmax_k$ is unchanged — Top-1 Accuracy is 100% preserved!

Take Home Points

  • Bias–Variance & Double Descent: Classical test risk balances $\text{Bias}^2$ and $\text{Variance}$, peaking at the interpolation threshold ($p = n$) before descending a second time as minimum-norm interpolants shrink $\|\hat{\vth}\|_2$ for $p \gg n$.
  • Why Raw Accuracy Fails: Under class skew ($95\%/5\%$), predicting the majority class everywhere achieves $95\%$ accuracy while failing on the rare class; manually rebalancing to $50\%/50\%$ reverses the winner in the wild.
  • Confusion Matrix Quotients: Sensitivity ($\text{TP}/\mathbf{P}$) & Specificity ($\text{TN}/\mathbf{N}$) normalize by true columns ($\to$ Balanced Accuracy); Precision ($\text{TP}/\text{Pred }\mathbf{P}$) & Recall ($\text{TP}/\mathbf{P}$) combine into $F_1$.
  • Expected Profit & ROC / AUC: When priors & costs are known, optimize $EV(\tau)$; when unstable, plot $\text{TPR}$ vs. $\text{FPR}$ (ROC), where $\text{AUC} = \PP(s(\vec{x}_{+}) > s(\vec{x}_{-}))$.
  • Model Calibration & Temperature Scaling: Deep networks overfit NLL and become overconfident; dividing logits by a single validation-tuned scalar $T > 0$ aligns $\hat{P}$ with true accuracy while preserving Top-1 Accuracy.
