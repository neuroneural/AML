Connecting the Dots: Why Stochastic Optimization?

1. ERM & Closed-Form Linear / Spectral Models
Linear regression and PCA solve $\nabla \prob{J}{\vth} = \vec{0}$ analytically via $(\bm{X}^T\bm{X})^{-1}$ or SVD in $O(Nd^2 + d^3)$ time.
2. Non-Closed-Form Convex Objectives
Logistic regression and SVMs couple parameters nonlinearly — requiring iterative gradient or QP solvers.
3. Non-Convex Landscapes & Latent Variables
Matrix factorization ($\bm{W}\bm{H}$), K-means, and GMMs introduce curved valleys, saddle points, and local optima.
4. The Big-Data & High-Dimension Wall
When $N \sim 10^8$ and $d \sim 10^9$, full-batch $O(N)$ gradients and $O(d^2)$ Hessians are computationally impossible.
5. Today: Stochastic & Adaptive Optimization
How do noisy $O(1)$ mini-batch gradients, momentum, and adaptive/spectral preconditioners train modern ML?

In early lectures, we had closed-form analytical solutions (Least Squares, PCA, Gaussian MLE). Then we met Logistic Regression, Matrix Factorization, and GMMs, where closed-form solutions vanish. Gradient Descent Variants

From $O(N)$ full-batch passes to $O(1)$ stochastic and mini-batch updates
Based in part on Sebastian Ruder (2016), An overview of gradient descent optimization algorithms.

Gradient Descent: Steepest Downhill Step

First-order iterative minimization of an objective function $\prob{J}{\vth}$
  • $\prob{J}{\vth}$: Objective / empirical loss function
  • $\vth \in \RR^d$: Parameters of the model
  • $\eta > 0$: Learning rate (step size along the negative gradient)
Update Equation
$\vth_{t+1} = \vth_t - \eta \nabla_{\vth} \prob{J}{\vth_t}$
Cauchy, A. (1847). Méthode générale pour la résolution des systèmes d'équations simultanées. Comptes Rendus Acad. Sci. Paris, 25, 536–538.

Why Can We Sample the Gradient?

In ERM and MLE, the total objective is an average over $N$ training examples $\{(\vec{x}_i, y_i)\}_{i=1}^N$:
$\displaystyle \prob{J}{\vth} = \frac{1}{N}\sum_{i=1}^N \loss(\vth; \vec{x}_i, y_i) \implies \nabla_{\vth}\prob{J}{\vth} = \frac{1}{N}\sum_{i=1}^N \nabla_{\vth}\loss(\vth; \vec{x}_i, y_i) = \EE_{i \sim \text{Unif}}\!\Big[\nabla_{\vth}\loss(\vth; \vec{x}_i, y_i)\Big]$
  • 1. Linearity of differentiation: The gradient of an average is the average of the per-sample gradients.
  • 2. Unbiased Mini-Batch Estimator: Draw a uniform random subset ${\cal B} \subset \{1,\dots,N\}$ of size $B = |{\cal B}|$:
    $\displaystyle \hat{\vec{g}}_{\cal B}(\vth) \;\def\; \frac{1}{B}\sum_{i \in {\cal B}} \nabla_{\vth}\loss(\vth; \vec{x}_i, y_i) \implies \underbrace{\EE\!\left[\hat{\vec{g}}_{\cal B}(\vth)\right] = \nabla_{\vth}\prob{J}{\vth}}_{\text{unbiased downhill direction!}}, \qquad \underbrace{\text{Cov}\!\left(\hat{\vec{g}}_{\cal B}(\vth)\right) \approx \frac{\bm{\Sigma}_g}{B}}_{\text{variance shrinks as } 1/B}$
  • Key Insight: Step cost scales as $O(B)$, while gradient noise std. dev. shrinks as $1/\sqrt{B}$!

Three Gradient Descent Variants

How many examples $B$ do we use per parameter update?
  • Batch Gradient Descent ($B = N$: entire dataset)
  • Stochastic Gradient Descent ($B = 1$: a single random example)
  • Mini-Batch Gradient Descent ($1 < B \ll N$: a small batch, e.g. $B = 32\text{–}512$)
Unified Update Rule
$\vth_{t+1} = \vth_t - \eta \, {\color{#dc322f} \hat{\vec{g}}_t(\vth_t)}$
The red gradient estimate $\hat{\vec{g}}_t$ is the only difference between the three methods!

Trade-Offs Across the Three Variants

Balancing update accuracy vs. wall-clock time per step
  • Accuracy of each gradient step: Variance scales as $\bm{\Sigma}_g / B$
  • Compute time per update: Evaluations scale as $O(B)$
Method Batch Size $B$ Step Accuracy Step Time Memory Online
Batch $N$ Exact ($\text{Var}=0$) Slow $O(N)$ High
Stochastic $1$ Noisy ($\text{Var}=\bm{\Sigma}_g$) Fast $O(1)$ Low
Mini-Batch $32\text{–}512$ Low Var ($\bm{\Sigma}_g/B$) Fast (GPU GEMM) Moderate

Batch Gradient Descent (B = N)

Compute the exact gradient of $\prob{J}{\vth}$ over the entire dataset
Update Equation
$\displaystyle \vth_{t+1} = \vth_t - \frac{\eta}{N}\sum_{i=1}^N \nabla_{\vth}\loss(\vth_t; \vec{x}_i, y_i)$
We must evaluate gradients for all $N$ examples to perform just one update. 

for epoch in range(number_of_epochs):
    gradient = eval_gradient(loss_fun, data, params)  # O(N) full pass
    params = params - eta * gradient

Batch Gradient Descent: Pros & Cons

Advantages
  • Deterministic trajectory on the exact empirical risk surface $\prob{J}{\vth}$
  • Guaranteed to converge to the global minimum (if convex) or a local minimum (if non-convex) for suitable $\eta$
Disadvantages
  • Prohibitive $O(N)$ compute cost per step when $N$ is large (redundant gradients across similar examples!)
  • Intractable when the full dataset exceeds RAM / GPU memory
  • Cannot incorporate new streaming data on the fly (no online learning)

Stochastic Gradient Descent (B = 1)

Perform a parameter update for each single training example $(\vec{x}_i, y_i)$
Update Equation
$\vth_{t+1} = \vth_t - \eta \nabla_{\vth} \loss(\vth_t; \vec{x}_i, y_i)$
Evaluates the gradient on a single data sample ($N\times$ faster per update!). 

for epoch in range(number_of_epochs):
    np.random.shuffle(data)  # Break ordering bias each epoch!
    for example in data:
        gradient = eval_gradient(loss_fun, example, params)  # O(1) cost
        params = params - eta * gradient

Stochastic Gradient Descent: Pros & Cons

Advantages
  • Makes immediate progress from the very first example ($N$ updates per pass through the dataset)
  • Natural fit for online / streaming learning where new samples arrive continuously
Disadvantages
  • High per-step variance $\bm{\Sigma}_g$ causes the objective $\prob{J}{\vth_t}$ to fluctuate heavily
  • Sequential $B=1$ updates underutilize modern SIMD / GPU vector hardware

Mini-Batch Gradient Descent (1 < B ≪ N)

The best of both worlds: low-variance updates + GPU matrix parallelism
$\displaystyle \vth_{t+1} = \vth_t - \frac{\eta}{B}\sum_{j=i}^{i+B-1} \nabla_{\vth}\loss(\vth_t; \vec{x}_j, y_j)$ 

for epoch in range(number_of_epochs):
    np.random.shuffle(data)
    for batch in batch_iterator(data, batch_size=32):
        gradient = eval_gradient(loss_fun, batch, params)  # GPU GEMM!
        params = params - eta * gradient
  • Pros: Shrinks gradient variance by $1/B$ and saturates GPU tensor cores via matrix-matrix multiplies.
  • Con: Adds mini-batch size $B \in \{32, 64, 128, 256, \dots\}$ as a hyperparameter (linear scaling rule: $\eta \propto B$).
Goyal, P. et al. (2017). Accurate, Large Minibatch SGD: Training ImageNet in 1 Hour (arXiv:1706.02677).

Stochastic Fluctuations

How stochastic gradient agitation escapes sharp local traps — and why $\eta_t$ must anneal to settle at $\vth^*$

The Fluctuations of Stochastic Updates

  • Batch GD: Follows a smooth, deterministic path straight into the nearest basin — getting trapped in sharp local minima.
  • SGD's Thermal Noise: Random per-sample kicks $-\eta\nabla\loss_i$ jump over narrow barriers into wider, flatter basins that generalize better!
  • The Catch: Near $\vth^*$, constant-$\eta$ SGD never halts — it orbits inside an $O(\sqrt{\eta\sigma^2})$ noise ball.
Keskar, N. S. et al. (2017). On Large-Batch Training for Deep Learning: Generalization Gap and Sharp Minima. ICLR 2017.

Learning Rate Annealing & Robbins–Monro

Why doesn't constant-step SGD stop at the minimum $\vth^*$?
  • At $\vth^*$, the full gradient is zero ($\nabla\prob{J}{\vth^*} = \frac{1}{N}\sum_{i=1}^N \nabla\loss_i(\vth^*) = \vec{0}$), so Batch GD halts automatically.
  • But individual sample gradients $\nabla\loss_i(\vth^*) \ne \vec{0}$ only cancel on average! With fixed $\eta$, SGD bounces perpetually inside a noise ball of radius $O(\sqrt{\eta \sigma^2})$.
  • To converge to $\vth^*$ (Robbins & Monro, 1951), decay $\eta_t$ so that:
    $\displaystyle \underbrace{\sum_{t=1}^{\infty} \eta_t = \infty}_{\text{can reach }\vth^*\text{ from any }\vth_0} \qquad \text{and} \qquad \underbrace{\sum_{t=1}^{\infty} \eta_t^2 < \infty}_{\text{cumulative noise variance }\sum \eta_t^2\sigma^2\text{ stays finite!}}$
  • Schedules in practice: Polynomial $\eta_t = \frac{\eta_0}{1 + \alpha t}$ (satisfies Robbins–Monro), Step Decay, Cosine Annealing $\eta_t = \frac{1}{2}\eta_0\!\left(1 + \cos\frac{t\pi}{T}\right)$.
Robbins, H., & Monro, S. (1951). A Stochastic Approximation Method. Ann. Math. Statist., 22(3), 400–407;   Loshchilov & Hutter (2017). SGDR: Cosine Annealing (ICLR 2017).

Momentum & Nesterov

Overcoming pathological curvature ($\kappa = \lambda_{\max}/\lambda_{\min} \gg 1$), narrow canyons, and oscillations

Four Core Challenges of Vanilla SGD

  • 1. Global Learning Rate Sensitivity: Too small $\eta \implies$ glacial progress; too large $\eta \implies$ divergence.
  • 2. Schedule Tuning: Annealing rates must be hand-tuned to problem geometry and dataset size.
  • 3. Uniform Step Size Across Coordinates: Uses the same scalar $\eta$ for both steep/frequent and flat/rare features.
  • 4. Ravines & Saddle Points: Oscillates wildly across narrow canyons and stalls on flat high-dimensional saddles.
Our Toolkit:   Momentum $\to$ Nesterov (NAG) $\to$ AdaGrad $\to$ RMSprop $\to$ Adadelta $\to$ Adam / AdamW $\to$ Muon
Ruder, S. (2016). An overview of gradient descent optimization algorithms (arXiv:1609.04747).

Pathological Curvature: Ravines & Conditioning

Local quadratic canyon $\prob{J}{\vth} = \frac{1}{2}\!\left(\lambda_{\min}\theta_1^2 + \lambda_{\max}\theta_2^2\right)$
  • Condition number $\kappa \def \frac{\lambda_{\max}}{\lambda_{\min}} \gg 1$ (steep walls $\theta_2$, gentle floor $\theta_1$).
  • Light Ball (Vanilla GD, $\gamma=0$): Zero inertia; gradient step $-\eta\nabla\prob{J}{\vth}$ points across the canyon and bounces wall-to-wall!
  • Heavy Ball (Momentum, $\gamma>0$): Physical inertia damps wall oscillations and accelerates down the $\theta_1$ floor (Goh, 2017).
Sutton, R. S. (1986). Two problems with backpropagation and other steepest-descent learning procedures for networks;   Goh, G. (2017). Why Momentum Really Works.

Heavy-Ball Momentum (Polyak, 1964)

Give the parameter vector physical inertia via a velocity vector $\vec{v}_t$
$\displaystyle \vec{v}_t = \underbrace{\gamma \vec{v}_{t-1}}_{\text{momentum }(\gamma \approx 0.9)} + \underbrace{\eta \nabla_{\vth} \prob{J}{\vth_t}}_{\text{current gradient pull}}, \qquad \vth_{t+1} = \vth_t - \vec{v}_t$
  • 1. Unrolling the recursion: $\vec{v}_t = \eta \sum_{\tau=0}^t \gamma^\tau \nabla_{\vth}\prob{J}{\vth_{t-\tau}}$ is an exponentially weighted sum of past gradients.
  • 2. Across steep canyon walls ($\theta_2$): Alternating signs $(+, -, +, -)$ cancel out, damping zig-zag oscillations!
  • 3. Along the valley floor ($\theta_1$): Steady gradients accumulate to terminal velocity $\frac{\eta}{1 - \gamma}\nabla\prob{J}{\vth}$ ($10\times$ speedup for $\gamma = 0.9$!).
Polyak, B. T. (1964). Some methods of speeding up the convergence of iteration methods. USSR Comput. Math. Math. Phys., 4(5), 1–17;   Qian, N. (1999). On the momentum term in gradient descent learning algorithms.

Nesterov Accelerated Gradient: Lookahead Step

$\displaystyle \vec{v}_t = \gamma \vec{v}_{t-1} + \eta \nabla_{\vth} \text{J}\big(\!\underbrace{\vth_t - \gamma \vec{v}_{t-1}}_{\text{lookahead }\tilde{\vth}_t}\!\big)$
$\displaystyle \vth_{t+1} = \vth_t - \vec{v}_t \qquad (\gamma \approx 0.9)$
  • Momentum: Evaluates $\nabla\prob{J}{\vth_t}$ at the old position, then blindly adds $-\gamma\vec{v}_{t-1}$.
  • Nesterov (1983): First steps to the lookahead point $\tilde{\vth}_t = \vth_t - \gamma\vec{v}_{t-1}$, then evaluates $\nabla\prob{J}{\tilde{\vth}_t}$ there to brake before overshooting!
Nesterov, Y. (1983). A method for solving the convex programming problem with convergence rate $O(1/k^2)$. Dokl. Akad. Nauk SSSR, 269, 543–547;   Sutskever et al. (ICML 2013).

Adaptive & Spectral Optimizers

From coordinate-wise second moments (AdaGrad, RMSprop, Adadelta, AdamW) to matrix orthogonalization (Muon)

AdaGrad: Per-Coordinate Adaptive Learning Rates

Duchi, Hazan & Singer (2011): Give rare/flat features large steps and frequent/steep features small steps
$\displaystyle \vec{g}_t = \nabla_{\vth}\prob{J}{\vth_t}, \qquad \underbrace{\vec{v}_t = \vec{v}_{t-1} + \vec{g}_t^2 = \sum_{\tau=1}^t \vec{g}_\tau^2}_{\text{cumulative sum of squared gradients}}, \qquad \vth_{t+1} = \vth_t - \underbrace{\frac{\eta}{\sqrt{\vec{v}_t + \epsilon}}}_{\text{effective }\vec{\eta}_t} \odot \vec{g}_t$
  • Why it works: Coordinates with huge past gradients ($v_{t,j} \gg 1$) have their step size automatically damped; sparse features ($v_{t,j} \approx 0$) keep full step size $\eta$.
  • The Fatal Flaw: Because $\vec{g}_\tau^2 \ge 0$, the sum $\vec{v}_t = \sum_{\tau=1}^t \vec{g}_\tau^2$ grows monotonically without bound ($\vec{v}_t \to \infty$).
  • Eventually $\eta / \sqrt{\vec{v}_t} \to 0$ and learning freezes completely before reaching the optimum!
Duchi, J., Hazan, E., & Singer, Y. (2011). Adaptive Subgradient Methods for Online Learning and Stochastic Optimization. JMLR, 12, 2121–2159.

RMSprop: Stop the Diminishing Learning Rate

Tieleman & Hinton (2012): Replace AdaGrad's unbounded sum with a leaky Exponential Moving Average
$$\begin{aligned} \vec{g}_t &= \nabla_{\vth} \prob{J}{\vth_t}, \qquad \prob{E}{\vec{g}^2}_t = \gamma \prob{E}{\vec{g}^2}_{t-1} + (1 - \gamma)\vec{g}_t^2 \quad (\text{leaky average, }\gamma \approx 0.9) \\ \vth_{t+1} &= \vth_t - \frac{\eta}{\underbrace{\sqrt{\prob{E}{\vec{g}^2}_t + \epsilon}}_{\text{RMS}[\vec{g}]_t}} \odot \vec{g}_t \end{aligned}$$
  • Divides each gradient coordinate by its local Root-Mean-Square $\text{RMS}[\vec{g}]_t$ over the last $\approx \frac{1}{1-\gamma}$ steps.
  • Ancient gradients decay exponentially ($\gamma^\tau \to 0$), so the step size adapts dynamically to current terrain!
Tieleman, T., & Hinton, G. (2012). Lecture 6.5—rmsprop: Divide the gradient by a running average of its recent magnitude. COURSERA: Neural Networks for Machine Learning.

A Subtle Flaw: Do the Parameter Units Match?

Zeiler (2012): Check the physical units of $\Delta\vth$ (assuming dimensionless objective $J$):
$$\begin{aligned} \text{1. SGD / Momentum:} \quad & \text{units of } \Delta\vth \propto \text{units of } \vec{g} = \text{units of } \frac{\partial J}{\partial \vth} \propto \color{#dc322f}{\frac{1}{\text{units of }\vth}} \\ \text{2. AdaGrad / RMSprop:} \quad & \text{units of } \Delta\vth \propto \text{units of } \frac{\vec{g}}{\text{RMS}[\vec{g}]} \propto \color{#cb4b16}{1 \quad (\text{dimensionless!})} \end{aligned}$$
$$\text{3. Newton's Method (2nd Order):} \quad \Delta\vth = -\bm{H}^{-1}\vec{g} \propto \frac{\partial J / \partial \vth}{\partial^2 J / \partial \vth^2} \propto \frac{1 / \text{units of }\vth}{1 / (\text{units of }\vth)^2} = \color{#859900}{\text{units of }\vth \; \checkmark}$$
Since $\Big|\frac{\partial^2 J}{\partial \vth^2}\Big|^{-1} \propto \Big|\frac{\Delta\vth}{\vec{g}}\Big|$, we restore the right units by multiplying by $\text{RMS}[\Delta\vth]_{t-1}$!
Zeiler, M. D. (2012). ADADELTA: An Adaptive Learning Rate Method (arXiv:1212.5701).

Adadelta: Matching Units Without Learning Rate η

Replace the arbitrary scalar $\eta$ in RMSprop's numerator with $\text{RMS}[\Delta\vth]_{t-1}$:
$$\begin{aligned} \vec{g}_t &= \nabla_{\vth} \prob{J}{\vth_t}, \qquad \prob{E}{\vec{g}^2}_t = \gamma\prob{E}{\vec{g}^2}_{t-1} + (1-\gamma)\vec{g}_t^2 \\ \Delta\vth_t &= -\frac{\text{RMS}[\Delta\vth]_{t-1}}{\text{RMS}[\vec{g}]_t} \odot \vec{g}_t = -\frac{\sqrt{\prob{E}{\Delta\vth^2}_{t-1} + \epsilon}}{\sqrt{\prob{E}{\vec{g}^2}_t + \epsilon}} \odot \vec{g}_t \\ \prob{E}{\Delta\vth^2}_t &= \gamma\prob{E}{\Delta\vth^2}_{t-1} + (1-\gamma)\Delta\vth_t^2, \qquad \vth_{t+1} = \vth_t + \Delta\vth_t \end{aligned}$$
Result: $\Delta\vth_t$ has the exact units of $\vth$, acts as a diagonal secant approximation, and needs no global $\eta$!
Zeiler, M. D. (2012). ADADELTA: An Adaptive Learning Rate Method (arXiv:1212.5701).

Adam: Adaptive Moment Estimation (2015)

Fuse Momentum (1st moment $\vec{m}_t$) + RMSprop (2nd moment $\vec{v}_t$) + Zero-Init Bias Correction
$$\begin{aligned} \vec{m}_t &= \beta_1 \vec{m}_{t-1} + (1 - \beta_1) \nabla_{\vth} \prob{J}{\vth_t} \qquad &&\text{(1st moment: Momentum EMA, }\beta_1 \simeq 0.9\text{)} \\ \vec{v}_t &= \beta_2 \vec{v}_{t-1} + (1 - \beta_2) \big(\nabla_{\vth} \prob{J}{\vth_t}\big)^2 \qquad &&\text{(2nd moment: RMSprop EMA, }\beta_2 \simeq 0.999\text{)} \\ \hat{\vec{m}}_t &= \frac{\vec{m}_t}{1 - \beta_1^t}, \qquad \hat{\vec{v}}_t = \frac{\vec{v}_t}{1 - \beta_2^t} \qquad &&\text{(Corrects }\vec{m}_0 = \vec{v}_0 = \vec{0}\text{ startup bias!)} \\ \vth_{t+1} &= \vth_t - \frac{\eta}{\sqrt{\hat{\vec{v}}_t} + \epsilon} \odot \hat{\vec{m}}_t \qquad &&(\epsilon \simeq 10^{-8}) \end{aligned}$$
Why divide by $1 - \beta_2^t$? At $t=1$ with $\beta_2=0.999$, $\vec{v}_1 = 0.001\vec{g}_1^2$ underestimates variance by $1000\times$ — without bias correction, the first step $1/\sqrt{\vec{v}_1}$ would be $\approx 31.6\times$ too huge!
Kingma, D. P., & Ba, J. (2015). Adam: A Method for Stochastic Optimization. ICLR 2015 (arXiv:1412.6980).

The Coordinate-Wise Optimizer Family & AdamW

Notable Extensions
  • AdaMax: $\ell_\infty$-norm second moment $\max(\beta_2\vec{v}_{t-1}, |\vec{g}_t|)$
  • Nadam: Nesterov lookahead inside Adam's $\hat{\vec{m}}_t$
  • AMSGrad: Non-decreasing $\hat{\vec{v}}_t = \max(\hat{\vec{v}}_{t-1}, \vec{v}_t)$
  • QHAdam / AggMo: Multi-damping momentum
  • AdamW (Loshchilov & Hutter, 2019): Decoupled weight decay
Why AdamW Beats Adam + $L_2$
Adding $\frac{\lambda}{2}\|\vth\|^2$ to $J(\vth)$ puts $\lambda\vth_t$ inside $\vec{g}_t$, so Adam divides weight decay by $\sqrt{\hat{\vec{v}}_t}$ — weakening regularization on large-gradient weights!

AdamW decouples decay directly on $\vth_t$:
$\displaystyle \vth_{t+1} = (1 - \eta\lambda)\vth_t - \frac{\eta}{\sqrt{\hat{\vec{v}}_t}+\epsilon}\odot\hat{\vec{m}}_t$
Rule of thumb: Use AdamW if in doubt — unless optimizing 2D hidden matrices, where Muon shines!
Dozat (2016) Nadam; Reddi et al. (2018) AMSGrad; Ma & Yarats (2019) QHAdam; Lucas et al. (2019) AggMo; Loshchilov & Hutter (2019) AdamW (ICLR 2019).

The Latest & Greatest: Muon Optimizer

Jordan et al. (2024) / Bernstein & Newhouse: Matrix-Aware Steepest Descent
  • Why Coordinate-Wise Adam Falls Short: Hidden layers are 2D matrices $\bm{W} \in \RR^{m\times n}$. Momentum $\bm{M}_t = \mu\bm{M}_{t-1} + \nabla_{\bm{W}}\prob{J}{\bm{W}_t}$ has skewed singular values ($\sigma_1 \gg \sigma_r$), so a few directions dominate while rare singular directions starve!
  • Muon's Idea (SVD $\bm{M}_t = \bm{U}\bm{\Sigma}\bm{V}^T$): Replace $\bm{M}_t$ with its nearest semi-orthogonal matrix ($\sigma_i \mapsto 1$ for all $i$):
    $\displaystyle \bm{W}_{t+1} = \bm{W}_t - \eta\,\text{Ortho}(\bm{M}_t), \; \text{Ortho}(\bm{M}_t) = \bm{U}\bm{V}^T$
  • Fast GPU Trick (No $O(n^3)$ SVD!): Normalize $\bm{X}_0 = \bm{M}_t / \|\bm{M}_t\|_F$ and run 5 steps of Newton–Schulz in $\text{bf16}$ ($<1\%$ FLOP overhead!):
    $\displaystyle \bm{X}_{k+1} = a\bm{X}_k + b(\bm{X}_k\bm{X}_k^T)\bm{X}_k + c(\bm{X}_k\bm{X}_k^T)^2\bm{X}_k$

The Rise of SGD: Large-Scale Learning


Bottou, L., & Bousquet, O. (2007). The Tradeoffs of Large Scale Learning. NeurIPS 2007 (NeurIPS 2018 Test of Time Award).
Explain why this 2007 paper won the NeurIPS Test of Time Award: before 2007, optimization researchers looked down on SGD because its convergence rate O(1/t) is much slower than Newton/L-BFGS quadratic convergence. Bottou & Bousquet proved why SGD wins anyway when N is huge!

Why O(1) SGD Beats O(N) Batch Solvers at Scale

Bottou & Bousquet (2007): Decompose total excess test risk ${\cal E}$ (recall Lectures 2–3!):
$\displaystyle {\cal E} \;=\; \underbrace{\big(\prob{R}{f^*_{\hclass}} - \prob{R}{f^*}\big)}_{{\cal E}_{\text{app}}\text{: Model Capacity}} \;+\; \underbrace{\big(\prob{R}{f_N} - \prob{R}{f^*_{\hclass}}\big)}_{{\cal E}_{\text{est}}\text{: Statistical Noise } \sim O(1/\sqrt{N})} \;+\; \underbrace{\big(\prob{R}{\tilde{f}_N} - \prob{R}{f_N}\big)}_{{\cal E}_{\text{opt}}\text{: Optimization Error } \le \rho}$
  • 1. Don't Over-Optimize Statistical Noise: Since empirical risk $f_N$ already differs from true risk $f^*_{\hclass}$ by ${\cal E}_{\text{est}} \propto 1/\sqrt{N}$, driving optimization tolerance $\rho \ll {\cal E}_{\text{est}}$ (e.g. $\rho = 10^{-12}$) gives zero test-set benefit!
  • 2. Fixed Time Budget $T_{\max}$: Batch GD / 2nd-order methods spend $O(N)$ per step to shrink $\rho$ exponentially ($\log\frac{1}{\rho}$), but can only afford a few steps when $N \sim 10^8$.
  • 3. Why SGD Wins: SGD's per-step cost is $O(1)$ (independent of $N$!) — to reach statistical precision $\rho \propto 1/N$, total time $T(\rho)$ is $O(1/\rho)$ for SGD vs. $O(N\log\frac{1}{\rho})$ for Batch GD!
Bottou, L., & Bousquet, O. (2007). The Tradeoffs of Large Scale Learning. Advances in Neural Information Processing Systems (NeurIPS), 20.

Take Home Points

  • Unbiased Mini-Batch Gradients: $\hat{\vec{g}}_{\cal B}(\vth)$ is an unbiased estimate of $\nabla\prob{J}{\vth}$ with cost $O(B)$ and variance $\bm{\Sigma}_g / B$, unlocking GPU matrix parallelism.
  • Noise Ball & Robbins–Monro Schedules: Constant-$\eta$ SGD oscillates in an $O(\sqrt{\eta\sigma^2})$ ball around $\vth^*$; annealing $\eta_t$ ($\sum \eta_t = \infty, \sum \eta_t^2 < \infty$) guarantees convergence.
  • Ravines, Momentum & Nesterov Lookahead: Steep canyons ($\kappa = \lambda_{\max}/\lambda_{\min} \gg 1$) make GD zig-zag; Momentum damps oscillations and NAG evaluates $\nabla\prob{J}{\vth_t - \gamma\vec{v}_{t-1}}$ at the lookahead point.
  • Adaptive Preconditioning (AdaGrad $\to$ RMSprop $\to$ AdamW): Normalizing by $\sqrt{\EE[\vec{g}^2]_t} + \epsilon$ with bias correction $(1-\beta^t)$ equalizes per-coordinate step sizes.
  • Muon & Large-Scale Learning: Muon orthogonalizes 2D momentum matrices ($\bm{U}\bm{V}^T$ via 5-step Newton–Schulz) so every singular direction advances equally; at large $N$, $O(1)$ stochastic steps beat $O(N)$ batch methods.
